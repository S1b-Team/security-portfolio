# Security Policy

## Reporting a vulnerability

If you find a security issue in this repository, including its lab code, please report it privately. Don't open a public issue.

- **How:** use GitHub private vulnerability reporting. Open the repository's **Security** tab and click **Report a vulnerability**.
- Please include: affected file or component, impact, and steps to reproduce (a minimal, non-destructive proof is enough).

## What to expect

- I'll acknowledge your report within 5 business days and keep you updated as I triage and fix it.
- I coordinate disclosure with you and credit you on publication if you'd like.
- Please give me reasonable time to fix the issue before disclosing it publicly.

## Scope

- **In scope:** the code and configuration in this repository.
- **Out of scope:** the intentionally vulnerable lab mode (`FIX=0`) behaving as designed, and any third-party systems. Never test against systems you don't own or aren't authorized to test.

## Safe harbor

Good-faith research that follows this policy, avoids privacy violations and service disruption, and stays within scope will not be pursued.
